# 📋 작업 브리프

**원 명령:** 휴대폰 통화내역을 텍스트로 변환하여 캐린더 일정에 추가하고 텍스트 내용을 간략히 요점하여 보여주며 만약 내용중에 어떤 약속이나 기타 특정날자에 납 품예약이 있으면 그날짜에 일정을 추가하는 안드로이드 어플을 만들계획. 보안 문제상 휴대폰 자체에서 만 실행되도록 만들어야함.

## 요약
휴대폰 통화내역을 텍스트로 변환하여 캘린더 일정에 추가하는 안드로이드 앱 개발 계획

## 분배
- **💻 코다리**: 안드로이드 앱을 개발하여 휴대폰 통화 내역을 텍스트로 변환하고 캘린더 일정에 추가하는 기능 구현. 보안 문제를 해결하기 위해 휴대폰 자체에서만 실행되도록 설계한다.
- **💼 현빈**: 개발한 안드로이드 앱의 비즈니스 모델을 분석하고 수익화 전략을 짜라
